🚀 Exploring Retrieval-Augmented Generation (RAG)

I’ve been learning and implementing **RAG (Retrieval-Augmented Generation)** — a powerful approach that combines information retrieval with language models to generate more accurate and context-aware responses.

🔍 What I worked on:
• Built a PDF-based Question Answering system
• Extracted text using PyMuPDF
• Generated embeddings using SentenceTransformers
• Implemented similarity search with FAISS
• Used HuggingFace pipelines for answering queries

💡 Key Learnings:
• How RAG reduces hallucinations in LLMs
• Importance of chunking and embedding quality
• Trade-offs between extractive QA vs generative models
• Basics of building a zero-cost RAG pipeline

📈 Currently improving:
• Better chunking strategies (overlap & semantic splitting)
• Enhancing retrieval accuracy
• Planning to integrate with a chat-based UI (Streamlit)

This is a small but important step towards building intelligent AI systems like ChatGPT-style assistants.
